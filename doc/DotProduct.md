# 点积运算单元（Dot Product Unit）规格说明

**版本**：1.0  
**作者**：Liu Yuxuan  

---

## 1. 概述

本文档描述了一种面向深度学习（DL）工作负载的**混合精度点积运算单元**的体系结构与功能规格。

该 DPU 通过在同一 Tensor Core 内集成多种精度的点积运算单元，实现跨精度、高吞吐的张量计算能力。在保证数值稳定性的同时，最大限度地降低硬件复杂度与功耗，适用于训练与推理等多种应用场景。

整体设计遵循以下原则：
- 支持多种浮点与整数精度的点积运算  
- 低精度计算统一累加到高精度累加器以保证数值精度  
- 根据精度特性选择不同的累加与对齐策略  

DPU 包含三个专用点积运算单元：

- **DP0**：FP64 点积单元  
- **DP1**：FP16 BF16 TF32 混合点积单元  
- **DP2**：E5M2 E4M3 点积单元  

---

## 2. 总体架构概述

### 2.1 设计理念

- 各点积单元均采用**多路并行**结构，以提高吞吐率  
- 采用 **FP32 作为统一累加格式**，降低长链点积的累加误差  
- 根据输入精度与动态范围需求，分别采用：
  - 块对齐压缩（Block-aligned Reduction）
  - 早期累加（Early Accumulation）
- 流水线深度针对不同精度进行定制，以平衡延迟、面积与功耗 

### 2.2 功能定义

DP 实现如下逻辑功能：
$$
D = \sum_{i=0}^{N-1} (A_i \times B_i) + C （TF32/BF16/FP16/INT8）
$$
$$
D = \sum_{i=0}^{N-1} (A_i \times B_i) \times sf + C （FP8/FP6/FP4）
$$

其中：
- $A_i, B_i$：浮点输入
- $C$：FP32 累加初值
- $D$：FP32 输出结果 **(均采用RNE舍入模式)**
- $sf$：缩放因子 scaling factor（8-bit）



## 3. 点积运算单元规格

### 3.1 DP0：2 路 FP64 点积单元

#### 支持精度

- 2-way **FP64（双精度浮点）**

#### 架构说明

DP0 为高精度点积计算单元，针对双精度浮点运算进行了优化。

该单元采用融合乘加（FMA）数据通路，并在内部保持扩展精度以降低舍入误差，适合对数值精度要求极高的计算场景。

#### 运算流程

- 并行计算两个 FP64 向量元素对的乘积  
- 使用 FMA 执行点积并进行中间累加  
- 最终结果以 FP64 精度输出  

运算分为以下阶段：

| 阶段 | 描述 | 周期 |
|----|----|----|
| 点积阶段 | FP64 乘法 + 部分累加 | 2 |
| 累加与舍入 | 最终 FP64 累加、规格化与舍入 | 2 |
| **总延迟** |  | **4 周期** |


### 3.2 DP1：中精度混合点积单元

#### 3.2.1 支持精度

| 输入精度 | 并行路数 | 累加精度 |
|----|----|----|
| TF32 | 4-way | FP32 |
| BF16 | 8-way | FP32 |
| FP16 | 8-way | FP32 |

**说明：**
- 所有模式下，最终累加器统一为 **FP32**
- 输入符号位与指数独立处理，尾数中间结果阶段位宽可配置
- 舍入模式均为 **RNE**

#### 3.2.2 微架构
##### (1) Stage 0: 输入与操作数提取
- 操作数接收：
  - 向量输入对：$\{A_0…A_{N-1}\}, \{B_0…B_{N-1}\}$
  - FP32 累加输入 $C$
- 操作数解码：
  - 符号位、指数、尾数分离
  - 非激活 lane 自动 gating（功耗优化）
  - 提取最大指数用于后续对齐
- 并行尾数乘法，指数加法：
  - 11-bit 尾数乘法器（TF32: 10/ BF16: 7/ FP16: 10）
  - 8-bit 指数加法器（TF32: 8/ BF16: 8/ FP16: 5）
- 找出向量中的最大指数：
  - 基于减法器的比较压缩树
- 输出：
  - 非规格化部分积（sign + extended mantissa + exponent）

##### (2) Stage 1: 部分和对齐与格式统一
- 所有乘法结果：
  - 对齐至 **最大指数**
  - 执行右移对齐（Alignment Shifter）
  - 转换为 **二进制补码表示（2’s complement）**

##### (3) Stage 2: 多操作数压缩加法
- 使用分级压缩树：
  - 4:2 Carry-Save Compressor
  - 3:2 Reduction（CSA）
- Carry Propagate Adder (CPA)：
  - 将 CSA 输出合并为最终和
  - 结果仍处于 FP32 扩展精度域
- LZA（Leading Zero Anticipator）：
  - 并行预测规格化移位量
  - 与 CPA 同周期工作，降低关键路径

##### (4) Stage 3: 规格化与舍入
- **Normalization Shifter**
  - 根据 LZA 输出执行左/右移
  - 生成标准 FP32 尾数与指数
- **RNE（Round-to-Nearest-Even）**
  - 支持 guard / round / sticky 位

#### 3.2.3 异常与边界条件（Optional）

- 支持：
  - ±0
  - 非规格化输入（flush-to-zero）
  - NaN / Inf

### 3.3 DP2：低精度高吞吐点积单元

#### 3.3.1 概述

DP2 支持 FP8/FP6/FP4 数据类型。  
该单元采用 **Early Accumulation（早期累加）** 微架构，在流水线前段即完成乘积的对齐与累加，显著减少中后段的大规模对齐与移位逻辑，从而实现 **更低面积、更低功耗和更高能效**。

DP2 的设计理念与 **Arm 4-way Fused FP8 Dot Product** 类似，但扩展支持更低精度路径，并最终统一累加到 **FP32 累加器**，保证数值稳定性。


#### 3.3.2 支持精度

| 输入精度 | 并行路数 | 累加精度 |
|----|----|----|
| FP8 | 16-way | FP32 |
| FP6 | 16-way | FP32 |
| FP4 | 32-way | FP32 |

**说明：**
- 所有模式下，最终累加器统一为 **FP32**
- 输入符号位与指数独立处理，尾数转定点格式全位宽累加，避免精度损失
- 舍入模式均为 **RNE**

#### 3.3.3 微架构

##### （1）Stage0: 操作数解码与缩放因子处理

- 操作数接收：
  - 多路低精度输入向量 $\{A_i, B_i\}$
  - FP32 累加器输入（sign / exponent / significand）
- 操作数解码：
  - 操作数解包（sign / exponent / mantissa）
  - 非使能 lane gating
- 每个 lane 包含：
  - 低比特宽乘法器（4-bit）
  - 指数加法器（5-bit）
  - 与 Anchor 做差（9-bit subtract）
- 缩放因子处理：
  - 与 Anchor 做差（9-bit subtract）得到缩放锚点值
  - 缩放锚点值与 FP32累加器 的指数比较大小，选取最大的作为指数主值
- 输出：
  - 未对齐部分积（带符号）

##### （2）Stage1: Early Accumulation 与右移对齐

- 每个部分积执行 **右移对齐（Right Shifter）**
- FP32 尾数根据阶段一得到的位移量做双向移位
- 对齐后结果：
  - 直接进入局部累加路径
- 多操作数压缩加法树
  - 累加结构：
    - **4:2 Reduction**
    - **3:2 Reduction**
    - **Carry Propagate Adder (CPA)**

##### （3）Stage2: 规格化与指数修正
- **LZC（Leading Zero Counter）**
  - 计算规格化左移量
- **Normalization Shifter**
  - 调整尾数
- **Exponent Update**
  - 通过 8-bit subtract 修正 FP32 指数

##### （4）Stage3: 舍入与输出

- **RNE（Round-to-Nearest-Even）**
- 输出：
  - 标准 FP32 格式结果 $D$


#### 3.3.4 异常与边界条件（Optional）

- FP 模式：
  - 支持 ±0
  - 非规格化输入（flush-to-zero）
  - NaN / Inf
